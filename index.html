Data storage

Entries, custom variables, and settings are kept only while this page is open. Refreshing, closing, or leaving the page clears them.

Journal data is not sent to a server or saved in browser storage. The app has no accounts, cookies, analytics, or journal file imports or exports. Records from older versions are not read.

GitHub hosts the app and may log website requests, including IP addresses. Journal entries are not included in those requests.
